# 🛍️ Customer Segmentation using K-Means Clustering

A simple Machine Learning project that groups customers based on their annual income and spending score using the K-Means Clustering algorithm.

---

## 📌 Project Overview

This project demonstrates how businesses can divide customers into different groups based on purchasing behavior. It uses the K-Means Clustering algorithm from Scikit-learn to perform customer segmentation.

---

## 🚀 Technologies Used

- Python
- Pandas
- Scikit-learn

---

## 📚 Machine Learning Concept

- Unsupervised Learning
- K-Means Clustering

---

## 📂 Features

- Creates a customer dataset
- Standardizes the data using StandardScaler
- Applies K-Means Clustering
- Assigns cluster labels to customers
- Displays segmented customer groups

---

## ▶️ How to Run

1. Install required libraries:

```bash
pip install pandas scikit-learn
```

2. Run the Python file:

```bash
python customer_segmentation.py
```
